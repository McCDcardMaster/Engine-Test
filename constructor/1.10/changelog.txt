Constructor changelog file
--------------------------
          v1.10

1 - Constructor now has two types of compiler 
	for assembling into an exe file:
		PyInstaller (default)
		Nuitka (new)

2 - Added new lib 'Nuitka' in 'dependencies.settings'

3 - Nuitka is compatible with the build.spec configuration file 
	or any other spec and uses metadata from it 
		if library imports are specified.
